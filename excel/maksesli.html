📈 Функция МАКСЕСЛИ в Excel

💡 Что делает функция МАКСЕСЛИ?

Функция МАКСЕСЛИ — это статистическая функция, которая находит максимальное значение среди ячеек, удовлетворяющих заданному условию.

Функция МАКСЕСЛИ используется для анализа данных, когда нужно найти наибольшее значение только среди элементов, соответствующих определённому условию.

📝 Синтаксис функции МАКСЕСЛИ

=МАКСЕСЛИ(диапазон; условие; [диапазон_поиска])
диапазон — диапазон для проверки условия
условие — критерий для отбора ячеек
диапазон_поиска — необязательный, значения для поиска максимума

🧮 Пример использования

Пример: Максимальная зарплата в отделе "IT"

Условие: В столбце A отделы, в столбце B зарплаты. Найти максимальную зарплату в отделе "IT".

Данные:
A1:A6 = {"IT", "HR", "IT", "Sales", "IT", "HR"}
B1:B6 = {50000, 40000, 55000, 45000, 60000, 42000}

Формула: =МАКСЕСЛИ(A1:A6; "IT"; B1:B6)

Расчёт:
Сотрудники отдела IT: A1, A3, A5
Их зарплаты: 50000, 55000, 60000
Максимальная: 60000
Результат: 60000

🔗 Связанные функции

МАКС — находит максимальное значение в диапазоне
МИНЕСЛИ — находит минимальное значение по условию
СЧЁТЕСЛИ — подсчитывает количество ячеек по условию
СУММЕСЛИ — суммирует значения по условию
