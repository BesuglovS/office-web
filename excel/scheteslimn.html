🔍🔍 Функция СЧЁТЕСЛИМН в Excel

💡 Что делает функция СЧЁТЕСЛИМН?

Функция СЧЁТЕСЛИМН — это статистическая функция, которая подсчитывает количество ячеек, удовлетворяющих нескольким условиям одновременно.

Функция СЧЁТЕСЛИМН используется для анализа данных, когда нужно найти количество элементов, соответствующих нескольким критериям одновременно.

📝 Синтаксис функции СЧЁТЕСЛИМН

=СЧЁТЕСЛИМН(диапазон_условия1; условие1; [диапазон_условия2]; [условие2]; ...)
диапазон_условия1 — первый диапазон для проверки
условие1 — первый критерий для отбора
диапазон_условия2, условие2, ... — дополнительные пары диапазон-условие

🧮 Пример использования

Пример: Количество сотрудников отдела "IT" с зарплатой больше 50000

Условие: В столбце A отделы, в столбце B зарплаты. Найти количество сотрудников отдела "IT" с зарплатой больше 50000.

Данные:
A1:A6 = {"IT", "HR", "IT", "Sales", "IT", "HR"}
B1:B6 = {50000, 40000, 55000, 45000, 60000, 42000}

Формула: =СЧЁТЕСЛИМН(A1:A6; "IT"; B1:B6; ">50000")

Расчёт:
Сотрудники отдела IT: A1, A3, A5
Их зарплаты: 50000, 55000, 60000
Зарплата > 50000: 55000, 60000 (2 сотрудника)
Результат: 2

🔗 Связанные функции

СЧЁТ — подсчитывает количество чисел в диапазоне
СЧЁТЕСЛИ — подсчитывает ячейки по одному условию
СУММЕСЛИМН — суммирует значения по нескольким условиям
СРЗНАЧЕСЛИМН — вычисляет среднее по нескольким условиям
