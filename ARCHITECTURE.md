# Архитектура проекта office-web

## Обзор

Статическое веб-приложение для изучения офисных приложений (Microsoft Office / LibreOffice). Основной фокус — интерактивные тренажёры по Excel с мгновенной проверкой ответов. Также содержит разделы по Word, PowerPoint и КуМир.

## Архитектура приложения

### Навигация

```
index.html (выбор раздела)
├── excel/index.html (каталог функций)
│   ├── summ.html          (14 функций + 2 задания ОГЭ)
│   ├── summesli.html
│   ├── ... 
│   └── oge14.html
├── word/index.html
├── powerpoint/index.html
└── kumir/index.html
```

### Структура тренажёра (Excel)

Каждый HTML-файл — самостоятельный тренажёр с inline CSS/JS:

```
Тренажёр (например, summ.html)
├── Теория
│   ├── Описание функции
│   ├── Синтаксис
│   └── Примеры использования
├── Интерактивная таблица
│   ├── Симуляция электронной таблицы
│   ├── Ячейки с данными
│   └── Поле ввода формулы
└── Проверка
    ├── Мгновенная валидация ввода
    ├── Визуальная обратная связь
    └── Подсказки при ошибках
```

### Типы функций

| Категория | Функции |
|-----------|---------|
| Суммирование | СУММ, СУММЕСЛИ, СУММЕСЛИ.МН |
| Среднее | СРЗНАЧ, СРЗНАЧЕСЛИ, СРЗНАЧЕСЛИ.МН |
| Подсчёт | СЧЁТ, СЧЁТЕСЛИ, СЧЁТЕСЛИ.МН |
| Поиск значения | МИН, МАКС, МИНЕСЛИ, МАКСЕСЛИ |
| Логика | И, ИЛИ, НЕ |
| Условия | ЕСЛИ |
| Адресация | Абсолютные, относительные, смешанные ссылки |

### Хранение данных

Прогресс сохраняется в `localStorage`:

| Ключ | Назначение |
|------|-----------|
| `office-progress` | Изученные функции |
| `office-theme` | Предпочтения темы |

## Дизайн-система

Общая с экосистемой:

- Фон: тёмный градиент
- Карточки: полупрозрачные с цветными акцентами
- Таблицы: симуляция электронных таблиц с сеткой
- Цветовая тема: жёлто-оранжевая (Excel), синяя (Word), оранжевая (PowerPoint)
