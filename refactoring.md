## 📋 Найденные проблемы

### 🔴 Критические проблемы

#### 1. Встроенный CSS во всех файлах
- **Проблема:** Каждый HTML файл содержит ~530-560 строк CSS в `<style>` (например, `esli.html` — 555 строк). CSS практически идентичен во всех файлах.
- **Влияние:** 
  - Повторение CSS кода в каждом файле (25+ файлов × ~540 строк = ~13 500 строк дубликата)
  - Файлы становятся огромными
  - Изменение стиля требует правки всех файлов
- **Решение:** Вынести CSS в общий `styles.css`

#### 2. Отсутствие JS модульности
- **Проблема:** Интерактивные тренажёры без JS разделения
- **Влияние:** Код inline в HTML, сложно тестировать
- **Решение:** 
  - Вынести логику в `js/trainer-{topic}.js`
  - Модульная архитектура

#### 3. Непоследовательная адресация
- **Проблема:** `oge14.html` (тренажёр) и `oge14-important.html` (теория) — разное назначение неочевидно из названий
- **Влияние:** Путаница в структуре
- **Решение:** Добавить document-префиксы или объединить (например, `oge14-trainer.html` и `oge14-theory.html`)

#### 4. Отсутствие навигации prev/next между темами
- **Проблема:** Есть ссылка «← На главную» и в Excel — «← Электронные таблицы», но нет кнопок «Предыдущая тема / Следующая тема» внутри раздела
- **Влияние:** Пользователь должен каждый раз возвращаться в индекс, чтобы перейти к следующей функции
- **Решение:** Добавить prev/next-навигацию (например, СУММ → СРЗНАЧ → СЧЁТ → ...)

#### 5. Нет сохранения прогресса
- **Проблема:** Тренажёры не сохраняют результаты
- **Влияние:** Потеря прогресса
- **Решение:** localStorage для отслеживания

### 🟡 Важные улучшения

#### 6. SEO и мета-теги
- **Проблема:** `<title>` есть в каждом файле, но `<meta name="description">` отсутствует во всех HTML-страницах
- **Влияние:** Поисковые системы не видят описания страниц, снижается CTR в выдаче
- **Решение:** Добавить `<meta name="description">` в каждый файл

#### 7. Доступность (a11y)
- **Проблема:** Нет ARIA-атрибутов, контрастность не проверяется
- **Влияние:** Проблемы для screen readers
- **Решение:** ARIA, проверенные цвета

#### 8. PWA / Офлайн
- **Проблема:** Нет manifest.json, sw.js, robots.txt, sitemap.xml — подтверждено при верификации
- **Влияние:** Нет офлайн-доступа, поисковые роботы не индексируют
- **Решение:** Добавить manifest.json, sw.js, robots.txt, sitemap.xml

#### 9. Аналитика
- **Проблема:** Yandex Metrika есть на index.html, но нет трекинга событий и счётчик не добавлен на страницы разделов (excel/*, word/*, powerpoint/*, kumir/*)
- **Влияние:** Неполная аналитика — неизвестно, какие темы популярны
- **Решение:** Добавить event tracking на все страницы

#### 10. Мобильная адаптация
- **Проблема:** `@media (max-width: 600px)` есть в каждом HTML-файле (25 шт.), но используется только один брейкпоинт. Нет адаптации под планшеты (768px+) и маленькие экраны (320-480px)
- **Влияние:** На промежуточных разрешениях (600-1024px) макет может выглядеть несбалансированно
- **Решение:** Добавить промежуточные брейкпоинты (480px, 768px, 1024px), тестирование на реальных устройствах

#### 11. Локализация
- **Проблема:** Только русский язык
- **Решение:** Добавить English перевод

### 🟢 Дополнительные улучшения
