# Руководство по внесению изменений (Contributing)

## Общая информация

Проект **Офисные технологии** — это образовательный ресурс на базе Академии Наяновой, посвящённый изучению офисных программ и подготовке к ОГЭ по информатике.

Разделы проекта:
- **Excel (Электронные таблицы)** — функции, формулы, адресация
- **Word (Текстовые редакторы)** — форматирование, таблицы
- **PowerPoint (Редакторы презентаций)** — создание слайдов
- **КуМир** — среда программирования

## Добавление новой темы

1. Создайте HTML-файл в соответствующей папке раздела (например, `excel/`)
2. Используйте следующую базовую структуру:
   - Подключите `../assets/css/styles.css`
   - Добавьте `<meta name="description">`
   - Добавьте ARIA-атрибуты (`role="main"`, `aria-label`)
   - Подключите скрипты: `topic-nav.js`, `progress.js`, `analytics.js`
   - Добавьте Яндекс.Метрику
3. Добавьте тему в `data/topics.json` в нужный раздел
4. Добавьте тему в `assets/js/topic-nav.js` в массив `TOPIC_ORDER`
5. Обновите `sitemap.xml` — добавьте новый URL

## Требования к коду

- **HTML**: валидный HTML5, семантическая разметка
- **CSS**: используйте переменные из `:root` в `styles.css`
- **JS**: ES5-совместимый код (без стрелочных функций, без const/let вне scope)
- **Доступность**: ARIA-атрибуты, осмысленный alt у изображений
- **Мобильная адаптация**: страницы должны корректно отображаться на экранах от 320px
- **Производительность**: минимизируйте использование внешних ресурсов

## Процесс внесения изменений

1. Создайте ветку от `main`: `git checkout -b feature/your-feature`
2. Внесите изменения
3. Проверьте вёрстку в браузере на разных разрешениях
4. Убедитесь, что Яндекс.Метрика работает корректно
5. Создайте Pull Request с описанием изменений

## Соглашения по именованию

- Файлы тем: латиница, строчные буквы, дефисы (например, `summesli.html`)
- CSS классы: kebab-case (например, `.theory-section`, `.nav-links`)
- ID элементов: camelCase (например, `trainerInput`, `checkBtn`)
